# To-Do List Appll

A simple browser-based to-do list app built with HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as complete or incomplete
- Delete tasks
- Filter tasks by All, Active, and Completed
- Clear completed tasks
- Save tasks in the browser using localStorage

## Run locally

1. Open the project folder in a browser, or serve it locally.
2. From the project directory, run:

```bash
python -m http.server 8000
```

3. Open this URL in your browser:

```text
http://localhost:8000
```

## Project files

- `index.html` – app structure
- `styles.css` – styling
- `script.js` – task logic and localStorage behavior

## Notes

This app runs entirely in the browser and does not require any dependencies or build tools.
